Tasks

Agent Studio tasks are stateless structured completions: one call, schema-checked output, honest timing. This kit is what the task demos build on.

The demos

  • Query rewriteraw search left, task states right
  • Rerankkeyword pool, then the agent's order slides in

The kit

  • common.jstask calls with cache bypassed, index search with an honest fallback ladder
  • page.jssetup guard, example chips, FLIP reorder for lists a task rearranges
  • style.csspanels, rows, badges — tokens from the shared kit, branding stays per page

A demo page brings its own task name, input shape and rendering; the kit brings everything else. Config comes from a tasks block in /shared/config.js: a search-only key on your app, plus the agent id that owns the task.

Timings on every demo are real: calls go out with cache disabled.
