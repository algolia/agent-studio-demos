    Methodology — read this before quoting any number

    These are order-of-magnitude planning aids, not quotes. Three rules:

    1. Every constant the arithmetic uses is on this page, so a reader audits the number instead of trusting it.
    2. Every figure is a ±50% band; deployments land inside it when the assumptions hold.
    3. A model with no defensible price shows no cost at all. Rows marked “no curated price” still estimate tokens; they refuse to invent dollars.

    Price scopes. Platform table rows use the exact per-1M-token table your bill is computed from, so an estimate cannot drift from the invoice. List rows are the provider's published price, named and dated. Placeholder rows say so; read the ratio, not the figure.

    Not priced: embeddings, indexing, A2A or MCP traffic, storage, dashboard calls, discounts. The workflow stays: run a PoC, measure, extrapolate; this sizes the PoC and checks the extrapolation.

    Arithmetic mirrors the platform's estimation service; every price names its source. Corrections welcome in data.js.
