# Product

## Register
product

## Users
Developers and builders evaluating Agent Studio, plus the team showing it to them.
They arrive curious, often from a link, with two minutes to spare. On the live
pages they are in a task: connect a test app, run something, read the result.

## Purpose
Public demos of Agent Studio features that show a mechanism working instead of
describing it. Each demo either replays a frozen, honest run or runs live on the
visitor's own app, never on ours.

## Brand personality
Precise, candid, quietly playful. Numbers lead and carry their n and interval.
Estimates say ≈. A weak result is shown as weak.

## Anti-references
SaaS landing pages: hero metrics, gradient text, icon-card grids, testimonials.
Explainer walls of text: if a sentence could be a visual state, build the state.

## Design principles
1. Show, don't tell: a state that changes on screen beats a caption.
2. Under two minutes to read a page: 400 visible words, grade 9 ceiling (CI-enforced).
3. Honest charts: rate axes run 0 to 100%, intervals on every comparison.
4. The visitor's data stays in their tab: keys never stored, writes fenced.
5. Boring, familiar controls: native inputs, one button vocabulary, no framework.

## Accessibility & Inclusion
WCAG 2.2 AA. Both themes from one token set (`shared/tokens.css`). Every chart
has an aria-label and per-point titles. Works at phone width with no sideways scroll.
